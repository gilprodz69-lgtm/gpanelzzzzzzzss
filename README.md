# VPS Manager

Painel de hospedagem para Ubuntu 24.04: sites, PHP 7.4 a 8.4, bancos, phpMyAdmin, arquivos e HTTPS.

Execute como **root**:

```bash
curl -fsSL https://raw.githubusercontent.com/gilprodz69-lgtm/gpanelzzzzzzzss/main/install.sh | bash
```

- **VPS nova:** instala e informa o endereço e os dados de acesso.
- **Painel instalado:** escolha **1 — Atualizar Painel**. Preserva sites, bancos, contas e configurações; faz backup antes da migração.
- HTTPS público exige IP/domínio acessível pela porta 80. Se a validação falhar, o painel informa o uso de certificado local.

Versão em desenvolvimento. [Estado dos módulos](docs/STATUS.md).
