# Referência aaPanel

Repositório indicado pelo usuário: [aaPanel/aaPanel](https://github.com/aaPanel/aaPanel).

A licença consultada está em [license.txt](https://github.com/aaPanel/aaPanel/blob/master/license.txt). Ela contém restrições para publicação de modificações e determinados usos do código em serviços concorrentes; também descreve aplicações baseadas na API. Por isso este projeto usa aaPanel como referência de capacidades e organização funcional, sem copiar código, interface, logotipos ou pacotes.

A interface deste projeto foi construída em HTML/CSS/SVG a partir da imagem de referência fornecida pelo usuário. Os dados exibidos vêm da aplicação; números e gráficos fictícios da referência não foram inseridos como métricas reais.

Uma integração opcional futura com a API do aaPanel deverá ser tratada como adaptador próprio, com revisão dos termos e requisitos de cada endpoint.
